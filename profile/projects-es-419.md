>

<details>
<summary><strong>Acerca de la clasificación y las evidencias de los proyectos</strong></summary>

- Un repositorio no es automáticamente un proyecto o una aplicación.
- Un repositorio puede contener varias aplicaciones independientes.
- Un proyecto puede aparecer en varias categorías.
- La sección Todos los Proyectos cuenta cada proyecto o aplicación una sola vez.
- Las tecnologías y funcionalidades solo se consideran demostradas después de verificarlas en el código.
- Cada proyecto tiene una fuente principal de detalles: el README del repositorio, una página agregadora, una página de subproyecto o una página de colección.

</details>
