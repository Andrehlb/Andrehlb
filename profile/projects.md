<summary><strong>Sobre classificação e evidências</strong></summary>

- Um repositório não é automaticamente um projeto ou uma aplicação.
- Um repositório pode conter várias aplicações independentes.
- Um projeto pode aparecer em várias visões temáticas, mas é contabilizado uma única vez no índice Todos os Projetos.
- Funcionalidades, tecnologias e integrações só são apresentadas como implementadas quando há evidência verificável no código.
- Estudos documentais demonstram aprendizado, não uma aplicação funcional.
- Planejado, parcial, em desenvolvimento, concluído e legado permanecem separados.
- A fonte principal pode ser um repositório, uma coleção, um subprojeto ou, quando indicado, código local ainda não publicado.
